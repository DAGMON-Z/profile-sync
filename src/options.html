Profile Sync

Your coding and security stats, wherever you want them. Not affiliated with any of the sites it reads.

Tracked

The easiest way to add one: open your profile on the site and click the extension's icon. Or add it here.

    With "Automatic" on, stats are also read whenever you have the site open, about once a minute. So new stats show up soon after you earn them.

    GitHub

    Writes a stats file and a card image for each tracked profile to one of your repos, in one commit, only when stats change. Put a card in a README with ![TryHackMe](profile-sync/tryhackme-you.svg).

    Signed in as ·

    Missing a repo? Give Profile Sync access to it, then press ↻. Profile Sync can only write to the repos you choose there.

    What happens on GitHub?
    • One commit per change, under your own name. Nothing is committed when nothing changed.
    • It only writes in its folder (profile-sync/) in the repos you picked. It never edits your README; add the card there yourself.
    • To check or remove access: GitHub → Settings → Applications → Installed GitHub Apps (which repos) or Authorized GitHub Apps (Revoke).

    Webhook

    Sends new stats as JSON to any address: your website, a server, Zapier, Make or n8n. Sent only when stats change.

    Discord

    Posts to a channel when your stats change: a level up, more solved problems, a new rank. Create the address in Discord: Channel settings → Integrations → Webhooks.
